# Behind-the-scenes photos (Home page: Mission / Vision / Performance)

Drop your photos into this folder with exactly these names:

| File name         | Shows next to       | Suggested photo                          |
|-------------------|---------------------|------------------------------------------|
| `mission.jpg`     | Our mission         | You teaching / guiding a class           |
| `vision.jpg`      | Our vision          | A shoot behind the scenes, team at work  |
| `performance.jpg` | Our performance     | Livestream in the studio, a launch event |

- Portrait works best (4:5, e.g. 1200 x 1500 px). On phones it is cropped to 4:3.
- JPG, under ~400 KB each, so the page stays fast.
- Until a photo is added, a "Behind the scenes" placeholder shows instead.

Intro videos and client testimonials are set in `deploy/site-media.js`.
