# Portfolio images

Drop new portfolio images in this folder, then add an entry for each one in
`../../portfolio-data.js` (templates are at the top of that file).

- Formats: JPG, PNG or WebP
- Size: about 1600px wide, under 500 KB each (compress with squoosh.app)
- Use lowercase file names with dashes, e.g. `nescafe-launch-poster.jpg`
- In the data file, refer to it as `assets/portfolio/nescafe-launch-poster.jpg`
