# Chinese font (字由点字玄真宋)

字由点字玄真宋 is a commercial font. After you buy a web-font licence from 字由 (hellofont.cn),
convert the font to WOFF2 and save it here as:

    tcm-xuanzhen-song.woff2

Then run `python3 tools/build_site.py`. Every Chinese page (/zh/) will use it automatically.
Until the file is here, the Chinese pages use 思源宋体 (Noto Serif SC), which is free for commercial use.
